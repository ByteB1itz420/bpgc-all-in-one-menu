# BPGC / food

Campus food menus for BITS Goa: weekly mess menu, outlets, night canteens, and a campus map. Prices and timings can change at the counter. The cart estimates a bill; it does not place an order.

## Run locally

`npm install` then `npm run dev`. Build with `npm run build`.

## Status

The admin panel is a local preview, not a secured multi-user admin system. Likes stay on each device until a Supabase project and its row-level security are configured. Never put a service-role key in client code.
